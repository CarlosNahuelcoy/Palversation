PALVERSATION - IMPORTANT
========================

This folder is only the in-game part of Palversation. On its own it does
nothing: your Pals' replies come from the Palversation launcher, a small
program that has to be open while you play.

Get the launcher here (free, no Python needed):
https://github.com/CarlosNahuelcoy/Palversation/releases

The launcher finds Palworld and installs this mod for you, so if you have
it you don't need this file at all.

Installing this folder by hand (optional):
1. Install UE4SS Experimental (Palworld) first.
2. Copy this "Palversation" folder into:
   ...\steamapps\common\Palworld\Mods\NativeMods\UE4SS\Mods\
   (it's already enabled: no need to edit mods.txt)
3. Open the launcher, press Connect Account, then Play.

In-game: deploy a Pal and type "!pal hello" in the chat.
